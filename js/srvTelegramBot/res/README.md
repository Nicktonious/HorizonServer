### Описание
<div style="color: #555">

Модуль реализует функционал службы *telegrambot** серверного фреймворка. Служба предназначена для трансляции значений каналов и минимального управления через команды Telegram. Служба НЕ занимается преобразованием значений в каналах и использует существующий функционал других компонент фреймворка. На данный момент присутствуют следующие команды:
- /start - вывод всех команд и возможностей бота;
- /on,/off,/reboot - включение, выключение и перезапуск подключенных к фреймворку ПЛК, каждая команда потребует последующего ввода индекса ПЛК для выполнения команды;
- /list - вывод всех активных каналов фреймворка;
- /val {chName} - вывод значения указанного канала (имя должно совпадать с тем, что указано в выводе команды /list);
- /temp - вывод текущего значения с датчика температуры;
- /light - вывод текущего значения с датчика освещенности;
- /sub,/unsub - подписка на события, генерируемые при переходе значений канала из зоны в зону. Сообщения приходят только с тех каналов, у которых указаны зоны.
</div>

### Подписки
<div style="color: #555">

- 'all-init-stage1-set' — инициализация службы;
- 'all-ch-alarm' — событие, генерируемое каналом при переходе значения в новую зону.
</div>

### Поля
<div style="color: #555">

- #_CurrTimeout — таймаут для выбора индекса ПЛК, после которого потребуется выбрать команду заново (равен 10 секундам).
- #_plcCommand — выбранная команда для ПЛК.
- #_plcReboot - флаг ПЛК, который находится в ребуте. При взведённом флаге нельзя выполнить другую команду.
- #_subContexts - массив ID чатов подписчиков на события.
- bot - объект класса пакета grammY, оперирует ботов на нижнем уровне.

</div>

### Конструктор
<div style="color: #555">

- _busList — список шин, созданных в проекте;
- _node — объект узла;
- _opts.token - объект с полем, содержащим токен создаваемого бота.

</div>

### Методы

<div style="color: #555">

- HandlerEvents_all_init_stage1_set(_topic, _msg) — обрабатывает событие инициализации, получает имена источников;
  
- HandlerEvents_all_ch_alarm(_topic, _msg) — принимает сообщение от канала, который перешел в новую зону, и отправляет его всем текущим подписчикам в читаемом формате.
</div>
